# Imagine City — โครงสร้างไฟล์

```
index.html            โครงหน้า + ลำดับโหลดสคริปต์
css/style.css         สไตล์ทั้งหมด
data/story.js         เนื้อหา: สาขา (MJ) ฉากคำถาม (SC) ซอยย่าน (AL) แบบฟอร์ม (PASS)
js/00-resize-sync.js  ปรับขนาดแคนวาสเมื่อเข้าโหมดคำถาม
js/01-core-state.js   สถานะเกม (S) และฟังก์ชันคิดคะแนน/ผลลัพธ์
js/02-sky-world.js    ท้องฟ้า ดาว เมฆ
js/03-city-art.js     ภาพเมือง แยกเป็นชิ้นตึก (buildComps)
js/04-story-camera-draw.js  กล้องที่เคลื่อนตามเรื่อง + ลูปวาดฉากหลัง
js/05-travel-and-audio.js   ทรานซิชัน + เสียง/เพลง
js/06-screens.js      หน้าจอข้อความ/ปุ่มทั้งหมด
js/07-actions-and-boot.js   การกดเลือก + เริ่มระบบ (boot)
js/08-scene-layer.js  ชั้นภาพประกอบต่อฉาก
js/09-button-feedback.js    เอฟเฟกต์ตอนกดตัวเลือก
js/10-intro-city.js   หน้าเปิดเรื่อง (เมืองลอย)
js/11-items-scene.js  ฉาก 1.2 ของติดตัว (ปัด/เด้งเข้าตัว)
js/12-back-button.js  ปุ่มย้อนกลับ
js/13-result-card.js  การ์ดผลลัพธ์ แตะหรือลากเพื่อพลิกด้านหน้า/หลัง (รูป images/card-front-<สาขา>.webp, card-back-<สาขา>.webp)
js/14-result-mascots.js     มาสคอตบนการ์ด + แอคชั่นตอนกด
js/15-floating-rocks.js     ก้อนหินเล็กๆ ลอยรอบเมืองในฉากหลัง (N จำนวน, SIZE ขนาด)
js/16-edge-rocks.js   หินลอยทับขอบกล่องข้อความทุกหน้า (ไม่ทับตัวหนังสือ)
js/17-home-rocks.js   หน้าแรก: แท่งหินคริสตัลใหญ่ลอยสองข้างเมือง (อยู่หลังกล่องข้อความเสมอ)
js/18-sun.js          หน้าแรก: ดวงอาทิตย์พิกเซลแบบเคลื่อนไหว (แทนดวงจันทร์กลม) ใช้ images/sun-sheet.webp
js/19-aurora.js       แสงออโรราเคลื่อนไหวเป็นฉากหลังชั้นไกลสุด (images/aurora.mp4) อยู่หลังทุกอย่าง
js/20-shop-scene.js   ฉาก 2.3 ร้านเก่าแก่ที่ใกล้ปิด: ร้านลอยเข้ามาจากซ้ายขวาประกอบฉาก (images/shop-left.webp, images/shop-right.webp)
js/21-card-open.js    หน้าผลลัพธ์: เอฟเฟกต์เปิดการ์ดพิกเซลก่อนการ์ดผลจริงโผล่ (images/card-open.webp)
js/24-result-share.js ปุ่มแชร์การ์ด: มือถือเปิดเมนูแชร์ (รูปสตอรี่ 1080x1920 + ลิงก์) คอมบันทึกรูป + คัดลอกลิงก์
tools/make-cards.py   สร้างรูปการ์ดทั้ง 5 สีจาก images/frame-1.png (หน้า) และ frame-2.png (หลัง)
editor.html           หน้าแก้เนื้อหา + พรีวิวสด (ใช้ js/editor.js, css/editor.css)
images/               รูปทั้งหมด (.webp) + ต้นแบบกรอบการ์ด frame-1.png / frame-2.png
```

**ลำดับโหลดสำคัญ** — ไฟล์ js ใช้ตัวแปรร่วมกัน (global) เรียงตามเลขใน index.html ห้ามสลับ
ไฟล์ 09–14 ครอบ (wrap) ฟังก์ชัน `render` / `mark` ของไฟล์ก่อนหน้าไว้ ลำดับจึงมีผล

**ต้องเปิดผ่านเว็บเซิร์ฟเวอร์** (เช่น Vercel หรือ `python3 -m http.server`)
ดับเบิลคลิกเปิดไฟล์ตรงๆ จะโหลดภาพเมืองไม่ได้เพราะข้อจำกัดความปลอดภัยของเบราว์เซอร์

## แก้เนื้อหาแบบเห็นผลทันที (editor.html)
เปิด `editor.html` ผ่านเว็บเซิร์ฟเวอร์ (เช่น `http://localhost:8000/editor.html`)
- ซ้าย: เลือกหน้า (ฉาก / ย่าน / บัตรผ่าน / ผลลัพธ์) แล้วพิมพ์แก้ ขวา: พรีวิวเกมจริงกระโดดไปหน้านั้นและเปลี่ยนตามทันที
- ช่องที่แก้แล้วมีกรอบสีเหลือง และบอกข้อความเดิมไว้ใต้ช่อง กด "ใช้ของเดิม" เพื่อย้อน
- ปุ่ม "แก้ไปแล้ว N จุด" แสดงรายการทุกจุดที่แก้ (ขีดฆ่า = เดิม, สีเหลือง = ใหม่) กดเพื่อไปที่ช่องนั้น
- งานที่แก้ค้างถูกเก็บไว้ในเบราว์เซอร์อัตโนมัติ แต่ยังไม่เปลี่ยนไฟล์จริง
- เสร็จแล้วกด "คัดลอก story.js" แล้วนำข้อความไปวางทับใน `data/story.js`
- เปิดจากหน้าเกมได้ด้วยการเติม `#editor` ท้ายลิงก์
- ข้อความหน้าแรกและหน้ากติกาอยู่ใน `js/06-screens.js` (หน้า editor ยังไม่ครอบคลุม)

## แก้อะไรที่ไหน
- แก้ข้อความ/คำถาม/คำตอบ → `data/story.js`
- เปลี่ยนรูป → ทับไฟล์ใน `images/` (ชื่อเดิม)
- ปรับการเคลื่อนไหวฉากหลัง → `js/04-story-camera-draw.js` (CAMP = กล้องต่อฉาก)
- ปรับของติดตัว → `js/11-items-scene.js` (XS/YS ตำแหน่ง, FIT ขนาด)
