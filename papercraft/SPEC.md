# Imagine City · สเปกฉากกระดาษป๊อปอัป

ทุกฉากในโฟลเดอร์นี้ต้องอ่านไฟล์นี้คู่กับ `PLAN.md` ก่อนลงมือ ห้ามแตะไฟล์เดิมของเว็บ (index.html, editor.html, js/, css/, data/, images/) จนกว่าจะถึงรอบต่อเข้าเว็บ
ความคืบหน้าและเรื่องที่รอตัดสินอยู่ใน `PROGRESS.md`

## 0. โครงไฟล์

```
papercraft/
  SPEC.md              ไฟล์นี้
  index.html           หน้ารวมฉาก: เลือกฉาก, ปุ่มทดลอง 5 สี (ย่าน 4 ข้อ), เล่นท่าเข้าฉากซ้ำ, พับลง, กล่องข้อความจำลอง
  shared.js            ชุดชิ้นส่วนใช้ซ้ำ + stage (renderer, กล้อง, นาฬิกา, เปิด/พับ)
  scenes/<id>-*.js     หนึ่งไฟล์ต่อหนึ่งฉาก (ES module, export default { id, build })
  vendor/              three.js r187 (three.module.js + three.core.js + LICENSE) ไม่พึ่ง CDN
```

เปิดดู: รันเว็บเซิร์ฟเวอร์ที่โฟลเดอร์ราก `fyqr-main` (เช่น `python -m http.server 8000`) แล้วเปิด
`http://localhost:8000/papercraft/` (หน้านี้อ่าน `../data/story.js` เพื่อเอาข้อความจริงมาใส่กล่องจำลอง)

พารามิเตอร์ URL สำหรับจับภาพ: `?scene=1-3` เลือกฉาก, `&box=0` ซ่อนกล่องข้อความ, `&ui=0` ซ่อนแผงเครื่องมือ,
`&t=2.5` หยุดภาพที่ 2.5 วินาทีหลังเริ่มเปิดฉาก (นาฬิกาคงที่ ได้ภาพเดิมทุกครั้ง), `&react=IGD&rt=1.4` กดสีแล้วเดินต่อ 1.4 วินาที

## 1. เรื่องและโลก

- เมืองที่สีหายไป กลางคืน คืนสุดท้ายก่อนเทศกาล หนังสือป๊อปอัปกลางคืนลอยอยู่ในท้องฟ้าของ Imagine City
- **ไม่มีตัวฮีโร่ในฉากไหน** ดวงไฟนำทาง (`guide()`, #FFF1B0) คือตัวแทนผู้เล่น: ลอยอยู่ในฉาก บินไปยังสิ่งที่ผู้เล่นเลือก (`flyTo`) และเป็นแสงหลัก
- หน้าตาของดวงไฟ: แอนิเมชันพิกเซล pixelfx `holy/sunburst` (120 เฟรม, 30 fps, วนซ้ำ) แปลงด้วย `tools/make-sunburst-atlas.py` เป็น `assets/sunburst-atlas.webp` (16x8 ช่อง, ~340 KB, ไม่เสียคุณภาพ) วาดเป็น sprite แบบบวกแสง + แสงเรืองเดิม · reduced motion ค้างเฟรมแรก · ตอนต่อเข้าเว็บต้องคัดลอกไฟล์นี้ไปด้วย
- สิ่งที่คนมองก่อน: ดวงไฟนำทาง แล้วจึงเป็นของสำคัญของฉาก
- **ข้อยกเว้นจากหลัก papercraft ทั่วไป:** ไม่ปูพื้นเต็มจอ เพราะต้องเห็นท้องฟ้า ออโรรา และเมืองของเว็บจริงข้างหลัง
  แต่ละฉากเป็น **หน้ากระดาษ / เกาะกระดาษขอบฉีก** ลอยอยู่ (`island()`) พื้นหลังของ canvas โปร่งใส

## 2. กระดาษ

- การ์ดแข็งด้าน ไม่มัน (MeshLambert ไม่มี specular) เยื่อกระดาษจาง ๆ (`P.fibre`)
- ความหนา ~2-3 % ของความสูงคนกระดาษ (~2.6 หน่วย): การ์ดทั่วไป `th: .07`, หน้ากระดาษ `.3` + แผ่นรองเข้มอีกชั้น
- ทุกลายพิมพ์เป็นงานตัดแปะซ้อนชั้น: แผ่นฐาน → โครงสร้าง (แถบ แผง) → ลวดลายเด่นที่ตัดกับฐาน (หมุด จุด ไอคอน)
  แต่ละชั้นทิ้งเงาสั้นสีกรมท่าออกจากแสง และมีขอบสว่างบาง ๆ เฉพาะด้านที่หันหาดวงไฟ (`P.layer`)
- ขอบตัด: เส้นหมึกเข้ม `#1E1A30` ที่ขอบรูป + ขอบสว่างด้านรับแสง ห้ามขอบขาวรอบตัวแบบสติกเกอร์
- ด้านข้างความหนาของการ์ดเป็นสีหมึก `#2B2440` จึงเห็นเป็นเส้นตัดบาง ๆ เอง

## 4. แสง

- แสงหลัก: PointLight `#FFF1B0` อยู่ที่ดวงไฟนำทาง (decay 1, power 13) วางด้านหน้า-ซ้าย-บนของจุดเด่น สูง ~50° จากของ
  เงาจึงตกไปด้านหลัง-ข้าง ที่กล้องมองเห็น
- เติม: Hemisphere ฟ้า `#8C88C8` / พื้น `#1A1438` 1.0 + Directional ด้านหน้า `#B8B2E8` .55 (~0.3 ของแสงหลัก)
- ลายพิมพ์คิดแสงจากซ้ายบน (`st.L = {x:-.6, y:-.8}`) ถ้าฉากไหนวางดวงไฟอีกฝั่งต้องกลับค่า L ให้ตรง
- ตอนกดตัวเลือก ดวงไฟกะพริบเป็นสีสาขาครู่หนึ่ง (`guide.flash(hex)`)

## 5. เลนส์และการจัดวาง (กล้องแยกแนวนอน / แนวตั้ง)

- PerspectiveCamera FOV 28° ก้มประมาณ 30° (ตั้งต่อฉากได้: `cam: { land: { pitch }, port: { pitch } }`)
- แต่ละฉากบอกกล่องขอบเขต 2 กล่อง (`frames`) ของท่านิ่ง:
  - `focus` = จุดสำคัญ (ดวงไฟ + ของหลักของฉาก) **ต้องอยู่ในแถบเหนือกล่องข้อความเสมอ** (บน 56px ถึงขอบบนกล่อง − 10px)
  - `wide` = ทั้งฉากรวมแผ่นข้าง ใช้เฉพาะจอแนวนอน
- **แนวนอน** (`st.orient === 'land'`, คอม 1280×800): ระยะกล้อง = ค่าที่มากกว่าระหว่าง "focus พอดีแถบบน" กับ "wide พอดีความกว้างจอ"
  แล้วเลื่อนภาพ (`setViewOffset`) ให้ focus อยู่กลางแถบ และ wide อยู่กลางจอแนวนอน ไม่ตกขอบล่าง
  **ใช้สองข้างกล่องข้อความ:** ฉากวาง `sidePage()` แผ่นกระดาษลอยซ้าย/ขวา ต่ำกว่าและใกล้กว่าแผ่นหลัก (ประมาณ x ±21, y −5, z +9)
  ให้อยู่ข้างกล่องข้อความ (กล่องกว้าง 460px กลางจอ) แผ่นข้างสร้างเฉพาะแนวนอน และมีไฟอุ่นของตัวเอง
- **แนวตั้ง** (มือถือ 390×844): focus พอดีแถบบน (กว้างเกือบเต็มจอ, สูง ~56–395px) ของนอก focus ตกขอบได้ แต่จุดสำคัญห้ามตก/ห้ามโดนบัง
  ไม่สร้างแผ่นข้าง (ประหยัดเครื่อง) เบาะแสสำคัญต้องมีอยู่ในแผ่นหลักด้วย
- ขอบบนกล่องข้อความ = เหมือนเว็บจริง `body.qa #app`: คอม `clamp(290px, 41vh, 430px)` / มือถือ ≤600px `clamp(330px, 48dvh, 470px)`
- เปลี่ยนแนวจอ = สร้างฉากใหม่ (หน้ารวมฉากทำให้อัตโนมัติ)
- ตึก/ของสูงด้านหลังตกขอบบนได้ (เป็นฉากหลัง) แต่ของที่ผู้เล่นต้องเห็นห้ามตก
- ความชัดตื้นแบบวาดไว้: หน้ากระดาษเบลอแถบไกลและแถบใกล้ในลายพิมพ์ (`island({ blurFar, blurNear, blurPx })`)
  ของไกลใส่ `blur` 2–3, ของใกล้มาก (พุ่มไม้หน้า) 3 ไม่ใช้ post-processing

## 6. การเคลื่อนไหว

- กระดาษเคลื่อนด้วยการหมุนรอบรอยพับเท่านั้น (`Hinge`) ไม่ขยาย ไม่ยืด ไม่จางเข้า
- เข้าฉาก: หน้ากระดาษพลิกลงจากแนวสันตรงหน้ากล้อง (เห็นเป็นเส้นก่อน จึงไม่ "โผล่") ~0.6 วิ
  แล้วการ์ดตั้งขึ้นทีละใบ ห่าง 0.07 วิ ตามลำดับ `order` ตั้งขึ้น ~0.25 วิ เด้งเกิน ~12 % นิ่งภายใน ~1 วิ
- ออก (`st.close()`): การ์ดพับลงย้อนลำดับ ห่าง 0.05 วิ นุ่มกว่า มีกระแทกเบา ๆ ครั้งเดียว แล้วหน้ากระดาษพลิกกลับเป็นเส้น
- ไหวตลอด: น้อยมาก (ผ้าคลุม ~1.5°, ดวงไฟลอย ±0.12) ถ้าสงสัย ให้ลดลง
- prefers-reduced-motion: ทุกอย่างตั้งตรงทันที ไม่เด้ง ไม่ไหว ดวงไฟไม่ลอย ตอนกดเปลี่ยนสีอย่างเดียว และหยุดวาดเมื่อนิ่ง

|---|---|
| `createStage(canvas)` | renderer โปร่งใส, กล้อง, แสงเติม, นาฬิกา, `mount / open / close / replay / react / seek / advance / stats` คืน `null` ถ้าไม่มี WebGL |

| `popRow(st, parent, pts, {colour})` | การ์ดเล็กสีสาขาพับตั้งทีละชิ้นตามแนว (ใช้ตอนกด) |

## 8. สัญญาของไฟล์ฉาก

```js
export default {
  id: '1-3',
  cam: { land: { pitch: 31 }, port: { pitch: 33 } },
  build(st, ctx) {            // ctx = { colour, alley, scores }   st.orient = 'land' | 'port'
    // 1) island()  2) guide()  3) ชิ้นที่ตั้ง  4) แผ่นข้าง (ถ้า st.orient === 'land')  5) ตัวตอบสนอง
    return { root, frames: { focus: {min,max}, wide: {min,max} }, react(m, i), reset() };
  }
};
```

- `react(m, i)`: m = รหัสสาขา (เหมือน `doAct(m)` ของเว็บ), i = ข้อที่กด (ย่านมี 4 ข้อ สาขาเดียวกัน ใช้ i แยกท่า)
- `ctx.scores` (5.1, 5.2): คะแนนจำลองจากหน้ารวมฉาก `{DGD, DGA, AFX, IGD, DEN}` ตอนต่อเว็บใช้ `scores(10)` ของเว็บ
- `reset()`: คืนสภาพก่อนกด (ใช้ตอนเล่นท่าเข้าฉากซ้ำ)
- ห้ามใช้ `Math.random` / เวลาจริง ใช้ `rng(seed)` และ `st.onUpdate((t, dt) => ...)`

## 9. งบประสิทธิภาพ (มือถือในงานอีเวนต์)

- ไม่ใช้ shadow map, ไม่ใช้ post-processing, `powerPreference: 'low-power'`
- pixel ratio: คอม ≤ 1.5, มือถือ ≤ 1.25
- วาดเฉพาะตอนมีฉากและแท็บเปิด; มือถือ 30 fps; เมื่อทุกบานพับนิ่งแล้วลดเป็น 30 fps ทุกจอ; reduced-motion หยุดวาดเมื่อนิ่ง
- สร้างฉาก: เป้า < 400 ms บนคอม (วัดใน headless SwiftShader ซึ่งช้ากว่าเครื่องจริง: ฉาก 1.3 ~400–800 ms)
- draw call: แนวตั้ง (มือถือ) ≤ ~160, แนวนอน (คอม รวมแผ่นข้าง) ≤ ~280 (ฉาก 1.3: 133 / 239) ถ้าเกิน: ใช้ `key` แชร์ลายพิมพ์, ปิดเงาชิ้นเล็ก (`blob:false`),
  หรือรวมการ์ดนิ่งเป็น atlas/BatchedMesh (ยังไม่ได้ทำ: งานก่อนขึ้นเว็บ)
- ออกจากฉาก: `dispose` geometry / material / texture ทั้งหมด (`st.mount` ทำให้แล้ว)
- three.js ตอนนี้เป็นไฟล์ไม่ย่อ (~2.1 MB, gzip ~420 KB) **ก่อนขึ้นเว็บจริงต้อง minify** (และ tree-shake เหลือเฉพาะคลาสที่ใช้ได้)

## 10. ห้าม

ผิวมัน/สะท้อน, ขอบขาวรอบชิ้นแบบสติกเกอร์, เงาสีเทาหรือดำ, การ์ดค้างเป็นแผ่นบางเห็นจากสัน (ระหว่างเคลื่อนไหวได้),
ชิ้นโผล่/จางเข้า, สีจัดเกินระดับของฉาก, ตัวอักษรบนป้าย, เส้นบางกว่า ~2–3 % ของชิ้น,
ของสำคัญอยู่หลังกล่องข้อความ, ไหว/เด้งมากจนดึงสายตาจากคำถาม
